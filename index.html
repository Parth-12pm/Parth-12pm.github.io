CH-03 // PROJECTS

12pm: Rootless VM Manager

[Go] [QEMU/KVM] [Cobra] [Cloud-Init] [Linux]

A fast, rootless, developer-first VM manager for Linux built in Go. Inspired by Docker's developer experience. Achieves 5.5s cold boot (8x faster than VirtualBox) via KVM acceleration and auto-optimized cloud-init. Features multi-VM management with dynamic port allocation, passwordless SSH, snapshot save/restore, stale PID auto-detection, and 9 switchable terminal themes.

AtriumVerse

[Next.js] [FastAPI] [Phaser 3] [LiveKit] [PostgreSQL] [Redis]

A tile-based virtual office platform where player position drives proximity audio, zone-based video, and messaging. Features zero-knowledge E2E encryption (X25519, ECDH, AES-256-GCM) with per-epoch key rotation, LiveKit WebRTC for proximity audio and zone video, Phaser 3 game engine for tile-based movement, and an async FastAPI backend.
